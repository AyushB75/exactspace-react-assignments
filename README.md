# Exactspace React Assignments

Two React applications developed as part of the Exactspace Technologies Front-End Developer Internship assignment.

## 1. Photo Gallery

A responsive, single-column photo gallery with infinite scrolling.

**Features**
- Fetches photos using the Picsum API.
- Infinite scrolling with paginated loading.
- Prevents duplicate photos.
- Individual like and unlike functionality.
- Loading, error, and retry states.
- Mock data mode for local testing when the API is unavailable.

**Tech Stack:** React, Vite, JavaScript, CSS, Font Awesome.

## 2. Real-Time Chat Application

A real-time chat application with live message synchronization.

**Features**
- Send and receive messages in real time.
- Random server-assigned usernames for messages.
- Like messages.
- Emoji picker with search.
- @mention support.
- Connection and reconnection handling.
- Responsive interface.

**Tech Stack:** React, Vite, JavaScript, Node.js, Express, Socket.IO, CSS.
